# 🔐 Password Strength Analyzer

A simple web-based tool that analyzes the strength of a user-entered password and provides suggestions to improve password security.

## 🚀 Features

* Checks password length
* Checks lowercase letters
* Checks uppercase letters
* Checks numbers
* Checks special characters
* Displays password strength
* Provides suggestions for stronger passwords
* Show/Hide password option
* Responsive and simple user interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

```text
Password-Strength-Analyzer/
│
├── index.html

└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Enter a password to analyze its strength.

## 🎯 Objective

The objective of this project is to understand basic password security concepts, input validation, JavaScript programming, and password-strength analysis.
