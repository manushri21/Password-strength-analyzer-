# Vulnerability Scanner

## Project Description

Vulnerability Scanner is a beginner-friendly Python mini project
that performs basic security checks on a system.

The project scans common TCP ports and identifies basic security
configuration issues.

## Features

- Common port scanning
- Basic service identification
- HTTP security header checking
- Risk identification
- Automatic vulnerability report generation

## Technologies Used

- Python
- Socket Programming
- File Handling
- VS Code

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

python vulnerability_scanner.py

5. Check the generated:

vulnerability_report.txt

## Project Output

The scanner displays:

- Target system
- Open ports
- Services
- Security warnings
- Scan completion status

## Safety

This project is designed for authorized testing,
such as testing your own computer or systems where
you have permission to perform security testing.
